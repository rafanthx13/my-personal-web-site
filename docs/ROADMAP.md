# Roadmap

## Ideias para o site

- Adicionar uma página ou modal de detalhes para cada projeto, mostrando o problema, a solução, tecnologias, imagens e resultados.
- Criar uma seção de resultados profissionais com números concretos, como sistemas entregues, processos otimizados ou ganhos de eficiência.
- Incluir um botão para download do currículo em PDF, além de uma versão em inglês do site.
- Exibir depoimentos curtos de colegas, clientes ou lideranças para reforçar credibilidade.
- Adicionar uma seção de artigos ou notas técnicas para compartilhar aprendizados sobre PHP, Laravel, dados e desenvolvimento de sistemas.
- Integrar uma atividade recente do GitHub, com os repositórios ou contribuições mais relevantes.
- Criar filtros na seção de projetos para separar desenvolvimento web, dados e engenharia de dados quando houver mais projetos publicados.
- Inserir uma chamada mais objetiva no contato, indicando os tipos de oportunidade ou parceria que você busca.
- Melhorar a visibilidade nos buscadores com título, descrição, Open Graph e dados estruturados voltados ao seu nome e especialidades.
- Adicionar métricas de acesso respeitando a privacidade, para entender quais projetos e canais de contato geram mais interesse.
